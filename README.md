# Pro Sewer Repair — design portfolio

Brochure and coordinated marketing concepts by **Brooke Howard / BaBBled LLC**. Heritage and Photo Series explore a shared yellow-and-black identity across pamphlets, posters / flyers, handbills and business cards.

## Role and permission

Graphic design, creative direction, marketing messaging, layout development and mockup presentation. The Pro Sewer owner permits showcasing the brochure. The gallery presents existing low-resolution, watermarked concept previews, without claiming final production approval, printing or campaign results.

Public business contact details printed in the artwork are intentional. Artwork and branding belong to their respective owners; portfolio display does not grant reuse rights.

## Contents

This standalone repository contains only the design gallery, its preview assets and a validation script, with fresh Git history. Client billing, payment documents, change orders, private correspondence and external client sharing links are excluded. No PDF, InDesign / IDML file, fonts, editable source package or printer production file is included.

The Photo Series business-card front is an earlier concept, labeled in the gallery. The later crew-and-vans front requires an intact original export. The review watermarks remain part of the previews.

## Local preview

Open index.html or serve this folder with a static server. JavaScript enables the side controls and image enlargement dialog. Preview images are intended for digital viewing and are not print production assets.

Run node --check script.js and node checks/portfolio-check.cjs. Browser validation covered 16 decoded images, all eight side switches and enlargement dialogs, Escape close, JavaScript errors and mobile overflow.

GitHub Pages publication is pending separate approval; creating this repository does not publish a live gallery.
